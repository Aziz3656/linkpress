# LinkPress

Paste a website link or import videos, choose 1080p / 720p / 480p / 360p / 240p, and get compressed MP4s.

- `desktop/`: Windows / Mac / Linux app (Electron + yt-dlp + ffmpeg). See `desktop/README.md`.
- `mobile/`: Android app (Flutter + yt-dlp + ffmpeg-kit) that saves straight to the Samsung Gallery. See `mobile/README.md`.

Android builds appear on the **Releases** page after every push.
